# energex-licence

The signed list of approved installs for the Energex Completion Packager, served by GitHub
Pages at `https://rodlunt.github.io/energex-licence/licence.json`.

The list holds only sha256 hashes of install IDs, and the app accepts it only with a valid
Ed25519 signature from the maintainer's key, so this file being public approves no one and
names no one. Nothing else belongs in this repo, and never the private key.
